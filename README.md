Investec Senior Tech Hub
Overview
Investec Senior Tech Hub is a user-friendly financial wellness platform designed for seniors. It
simplifies digital banking, card management, and fraud prevention while ensuring accessibility
through large text, voice commands, and intuitive navigation.
Key Features
- Secure Login - Large text, easy navigation, and wallet icon branding.
- Card Management - Add, lock/unlock, and set spending limits for cards.
- Fraud Detection - Alerts for suspicious transactions.
- Interactive Learning - Educational modules on safe online banking.
- Emergency Contact Access - Quick access to trusted contacts.
Getting Started
Prerequisites:
- Node.js installed (if using React)
- A Replit or GitHub account
- A browser supporting accessibility features
Installation:
1. Clone the repository:
 git clone https://github.com/your-repo/investec-senior-tech-hub.git
2. Navigate to the project folder:
 cd investec-senior-tech-hub
3. Install dependencies:
 npm install
4. Run the app:
 npm start
Testing Checklist
- Is the wallet icon properly displayed on the login page?
- Are text sizes readable?
- Can users lock/unlock their cards easily?
- Does the daily limit field prevent negative values?
- Are all currency amounts formatted properly?
- Are fraud alerts working as expected?
